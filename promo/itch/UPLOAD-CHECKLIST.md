# itch.io upload checklist

1. Create a new project from your itch.io dashboard.
2. Set the title to **PRISM — AI Stem Studio**, project type to **Tool**, and price to **Free**.
3. Add the short description, tags, cover and screenshots from `PAGE-COPY.md`.
4. Paste the description into itch.io's editor and make the launch link prominent.
5. Set the project Homepage / external link to `https://vicsanity623.github.io/`.
6. Use the dark theme. Keep the page focused on the editor, privacy and getting started.
7. Preview on desktop and mobile, then publish when the live site is pushed and verified.

The live site is hosted on your approved domain. Keep the itch.io page as a discovery page that links out to the app rather than embedding a second copy.
