The essentials on using the browser studio, models, privacy and exports.

Is PRISM free to use?

Yes. The browser editor is free to use and supported by advertising on informational pages. You do not need an account to open the editor. Your internet provider may charge for data; the AI model download is approximately 166 MB.

Does my audio get uploaded?

The editor processes imported audio locally in your browser. It does not send the audio file to a PRISM server. If you use AI separation, the model weights are fetched from Hugging Face. Normal web hosting, advertising and network providers may process standard request data; see the Privacy Policy.

Which AI models work in the website?

The current hosted browser build includes HTDemucs-FT and HTDemucs ONNX models, loaded on-device through ONNX Runtime Web. MDX-Net is not enabled in this browser build; the MDX mode in the desktop source requires a separate local Python service.

Why does the model take a while to download?

The HTDemucs-FT model is about 166 MB. It is downloaded only when you select AI separation, and the browser tries to cache it for future use on the same device and browser. Clearing site storage may remove the cached model.

Does it run on a phone?

Some recent phones support WebGPU, but AI separation is memory intensive and mobile browsers can close large tasks. A desktop or laptop with a recent browser and several gigabytes of available memory is recommended. DSP modes are lighter.

Why are the separated stems imperfect?

Source separation estimates instruments from a finished mix. Reverb, doubled vocals, distortion, overlapping instruments and mastering can create bleed or artifacts. Results vary by song and are not a substitute for original multitrack recordings.

Can I export the stems?

Yes. Use Export to create a mix, individual track or all-stems export, and to save a project bundle. Browser support and available memory can affect file formats and maximum project size.

Are my sessions saved online?

No account-based cloud sync is provided by this static site. Export your project bundle or session file if you want to keep it or move it to another device.

Why is there a Google sign-in button?

Google sign-in is optional and preserved from the previous site. It is not required to use the editor and does not enable cloud audio processing or project storage in this version.

Can I use separated audio commercially?

PRISM cannot grant rights to the source recording or composition. You are responsible for having permission to use, process and publish the audio and for complying with the licenses and rights that apply to it.
